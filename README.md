# DocCraftTools v4.1 — Search Content Expansion

A clean static website focused on organic discovery from Google Search and Bing.

## Included
- Homepage and tools directory
- Functional invoice, receipt, quotation and purchase-order generators
- VAT calculator
- 24 original business-document guides across six topic clusters
- About, contact, privacy, terms and 404 pages
- XML sitemap, robots.txt, canonical tags and JSON-LD
- Article, breadcrumb and FAQ structured data on the new guides

## Search architecture
The guide library is grouped into Invoices, Receipts, Quotations, Purchase Orders, VAT and Business Basics. Every guide links to a relevant browser-based tool and related learning pages.

## Deployment
Upload the contents of this folder to the web root for `doccrafttools.com`. Test on a staging URL first.

## Search launch checklist
1. Verify the production site in Google Search Console and Bing Webmaster Tools.
2. Submit `https://doccrafttools.com/sitemap.xml` to both.
3. Inspect the homepage, tool URLs and a representative guide from each topic cluster.
4. Confirm canonical URLs resolve over HTTPS with one preferred host.
5. Review search performance before creating additional pages; expand only where a distinct user question exists.

No social-media, paid-advertising or email-marketing dependency is included.
